# Dashboard do Clã Joji Clã

## Sobre a Aplicação

Este é um painel de controle (dashboard) para visualizar as estatísticas do nosso clã no Clash Royale.

**Funcionalidades Principais:**
*   **Visão Geral do Clã:** Informações gerais, troféus e requisitos na página inicial.
*   **Painel de Atividade:** Listas de Top 5 doadores e membros inativos na página inicial.
*   **Análise de Guerra:** Uma página detalhada que mostra a performance de todos os membros na última guerra.
*   **Ranking de Membros:** Classificação completa de todos os membros por troféus.

A aplicação foi desenvolvida utilizando HTML, CSS e um servidor local com Node.js/Express para buscar os dados em tempo real da API oficial da Supercell de forma segura.

## Instruções para os Membros do Clã

Bem-vindos ao nosso dashboard!

Use este painel para acompanhar nosso desempenho nas guerras, ver quem mais está doando e ficar por dentro das estatísticas do clã. A participação ativa na guerra e as doações são fundamentais para o nosso crescimento. Vamos crescer juntos!
